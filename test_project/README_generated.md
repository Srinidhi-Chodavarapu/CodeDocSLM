## Overview

project is a Python package that provides utilities for mathematics,
data processing, and user management. It includes functions to check if a number
is prime or in the Fibonacci sequence, a class to represent matrices, a utility
to validate email addresses, a data processor class with methods to format currency
and process data, a user manager class with methods to calculate average scores,
add users, and find users by name, and a Java class for a simple calculator with basic
arithmetic operations.

## Quick Start

### Python

```bash
# Clone and setup
pip install -r requirements.txt

# Import and use

```

### JavaScript

```bash
# Install dependencies
npm install

# Run
npm start
```

### Java

```bash
# Build
mvn clean install

# Run
mvn exec:java
```
